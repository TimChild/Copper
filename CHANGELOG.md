# Changelog

What changes in Copper from one version to the next, newest first.

**Unreleased** gathers what is done since the last version, as it lands:
every fix and every addition gets its line the day it is merged. When a
version ships, the section takes its number and date, its gist becomes the
paragraph in `NOTES.md` (what Settings and the updater show), and the list
is what gets posted as the update. What is planned but not done yet lives
in [ROADMAP.md](ROADMAP.md).

## Unreleased

### Added (Copper)

- **Pins are the same in every space.** One set of pins, as Arc's Favourites: pin a tab in any space and it is at the top of every space's column and every window's; unpin it and it leaves them all, staying a loose tab in the space you unpinned it in; a new letter or a drag to a new place shows everywhere at once. It is one tab with one page wherever it shows, so picking a pin that another window is on brings it over, as any tab does. The grid stays put while the column slides to another space; a pin is not offered Move to Space, deleting a space never closes one, and a space's tab count leaves them out. Yesterday's pins from every space merge into the one set at first launch — space by space, an address pinned in two spaces kept once — and Arc's favourites and Chrome's pinned tabs from Move in join it the same way. `session.json` holds them once in a top-level `pins` list, plus a copy in the front space for an older build to find, which this one skips.

- **Two-step codes fill from Bitwarden when you click the code box.** A one-time-code box (`autocomplete=one-time-code`, or a field named like otp/2fa/verification code) now lists a *Two-step code* row for each Bitwarden login on the site that has an authenticator key, with the account you just signed in with in that tab first — the code page is often on another host. Picking it computes the current code locally from the seed (`bw get totp` as fallback) and fills it, single box or one box per digit; nothing fills on its own. Before, the list showed accounts and filled the password into the code box. A password pick no longer holds the code list back when the page swaps the sign-in for the code step. `./bench bw rows` / `bw pick ROW` drive the list. Verified live on github.com.
- **Spaces follow you across windows.** Copper's windows now share one live set of spaces and tab rows, while each window keeps its own place and active tab; moving, pinning, grouping or closing a tab is reflected everywhere without mounting one web view twice. Picking a tab that is on another window's stage brings it over, and that window falls back to a tab nobody is showing — or, when there is none, says *is open in another window* with **Show Here** and **New Tab**. ⌘W, a space switch and the archive sweep leave tabs another window is showing alone; the split view belongs to one window at a time; the space slide and the two-finger swipe run in the window they belong to. `windows.json` keeps each window's space and the address of its tab (a tab's id changes every launch), and folds the old per-window rows into their space on first launch.

- **Chrome-style developer shortcuts.** `⇧⌘R` clears the current site's cache without touching cookies or storage, then reloads from origin; `⇧⌘I` opens Web Inspector with element selection. Both are also in the View menu and ⌘K command bar, while Reading mode moves to `⌥⌘R`.

- **Choose which way a swipe moves the column.** Settings › Tabs › Swipe between spaces: Natural (the column follows your fingers), Inverted (it moves the other way, so fingers to the left bring in the space before), or Like scrolling — the default — which follows the Mac's Natural scrolling setting (`com.apple.swipescrolldirection`; off on Collin's Mac, so his default is now Inverted). The drag, the release springs, the rubber band at the first and last space, three-finger swipes and the Reduce Motion trigger all follow it. `./bench spaces swipe direction [system|natural|inverted]` reads or sets it.
- **You can see which agent is using which tab.** Every agent session gets its own colour (nine hues, kept per thread, never Copper's own orange or the space's tint) and a small square with its initial on each tab it is touching or touched in the last 30 s, in the sidebar and the tab strip; several agents stack. While one drives the tab in view, a capsule at the top of the page reads "Claude Code · <thread>" in its colour and the ring round the page takes that colour too. Hover any square or capsule for who, which thread, what it is doing now, since when, and Stop (Stop now refuses only that session, not every agent). The thread is `COPPER_AGENT_THREAD` if set, else the P3/T3 thread title looked up from the agent's `CLAUDE_CODE_SESSION_ID`, else the project folder and a short session id; the `--mcp-stdio` bridge and `copper` CLI send it in an `X-Copper-Agent` header, HTTP clients get an `Mcp-Session-Id`, and a Jev run is labelled with the thread that started it. `./bench drive fake NAME THREAD [tab N] [--for S]` and `./bench render hands PATH` picture it.
- **Moving in from Arc brings its local storage and keeps the window live.** The Move in sheet has a Local storage switch (on, with Signed-in state, by default): Copper reads every Arc profile's localStorage LevelDB itself — a copy, never Arc's files — and sets it origin by origin into the shared website store, and a profile's own into the store of any space that wears that profile. On Collin's Arc: 884 sites, 11,951 keys in about 90 s, identical to `arc-localstorage`'s output; Linear, GitHub and Slack open with every key Arc had. The whole move is now off the main thread, the keychain ask for "Arc Safe Storage" included, so the window no longer freezes behind that prompt. A finished Arc move is remembered: the sheet says "Moved from Arc on <date>" with Move again instead of the big button. Chrome and Brave go through the same reader (not yet run against them live). `./bench flow move --source Arc --only localstorage[,cookies]` drives it; `./bench flow localstorage --source Arc --path OUT.json` writes the reader's JSON for diffing. IndexedDB is still not carried over.
- **Copper's own default column.** A space with no colour of its own now wears a built-in picture drawn from the app icon: pale rose-copper with soft verdigris ribbons and a faint brushed sheen, light enough for the rows to read. It's offered first among the pictures in Settings › Spaces; Graphite is still grey, and picking any colour drops the default picture.

- **Spaces and Extensions are pages of Settings.** Settings › Spaces (after Tabs) shows every space across the top — click to pick, drag to reorder, + for a new one — and under it everything the Space page had: a live column preview in light or dark beside the name, look and profile, then the icon, colours, picture or scene, Intensity / Grain / Blur / Tone and Delete. Settings › Extensions is the whole extensions manager: search, Chrome Web Store, Load Unpacked, every extension with its switch, pin, Details (site access, permissions, shortcuts, errors, folder), Options, Reload and Remove, and the paste-a-link field. Clicking the current space's icon (at the foot or in the title row), Edit Space… and ⌘K's Edit Space open Settings › Spaces on that space; the foot's puzzle door, the address pill's puzzle piece and every Manage Extensions… open Settings › Extensions. Another space's chip still just switches to it. The cards over the window are gone; `./bench spaces page N`, `spaces tap`, `ext-manager open|manage|toggle` drive the Settings pages, and `spaces picture` / `ext-manager picture` draw them.
- **Arc's localStorage comes along.** `./arc-localstorage OUT.json` reads every Arc profile's localStorage straight out of its LevelDB (a copy, never Arc's own files; nothing to install) and `./bench storage import OUT.json [--only ORIGIN] [--profile-store NAME]` puts it into Copper's website store one origin at a time, without loading any site. On Collin's Arc: 880 origins, 11,892 keys in under a minute; the three origins over WebKit's 5 MB quota keep what fits. IndexedDB, sessionStorage and third-party (partitioned) storage are not carried over.
- **Swiping between spaces follows your fingers, like Arc.** Two fingers sideways over the column now drag it 1:1 with the neighbouring space coming in beside it (its column as last seen, from a per-space picture taken whenever you leave or arrive), the lights, address and strip crossfading by the same amount. Let go past ~38% or with a flick (over 350 pt/s) and it springs the rest of the way at your fingers' speed, the real switch made under the picture; short of that it springs back. The first and last spaces rubber-band instead of wrapping; momentum after the lift is swallowed; content follows the fingers whatever the scroll direction. Reduce Motion keeps the old 70-point trigger. Keyboard, menu, click and mouse thumb-button switches keep the timed slide. With several windows the swipe drives the column under the fingers and only that one; `./bench spaces swipe DX,DX,…[ end|cancel] [--hold] [--shot PATH@MS] [--window N]` scripts a gesture through the same path.
- **The column bounces at its ends.** Scrolling the sidebar past its top or bottom now rubber-bands like a native list, even when the rows fit; sideways elasticity is off so it never fights the space swipe. `./bench spaces scroll` reports the scroll view's elasticity.
- **Switching spaces slides, like Arc.** The old column slides out and the new one slides in as two layers in 0.22 s, instead of every row animating on its own; the lights, address and space strip stay put and the theme crossfades. Motion starts 35–70 ms after the click (the snapshot is a 1–4 ms compositor copy), and middle-click closing uses one listener for the whole column instead of one per row.
- **Mouse thumb buttons switch spaces over the sidebar.** Back goes to the previous space and forward to the next, with the same glide as a two-finger swipe; over a page they still navigate back and forward, and with one space they are swallowed without changing anything.

- **An Extensions page, and a door to it that is always there.** A puzzle door beside the library at the foot of the column (and the address pill's puzzle piece, and every Manage Extensions…, in either layout) opens one card with every extension: its icon, version and description, on/off, pinned beside the address, Options, its popup, Reload and Remove (which asks first). Details shows the sites it may read and change — each can be taken back, and stays taken back — what it may do, anything it was allowed later (revocable), its keyboard shortcuts, the errors it reported, and for an unpacked one its folder with Reveal in Finder. Search, the Chrome Web Store, Load Unpacked and a paste-a-link field sit on the card too.
- **⌘T asks before it opens anything, the way Arc's does.** The ⌘K card comes up in new-tab mode: the first row is what Return does (Open example.com, or Search Google for “…”), then Google's live completions, open tabs to switch to (this space first, then other spaces wearing their name), history ranked by how often and how lately, bookmarks and commands. Empty, it lists the tabs you were just on — most recent first, across space switches — so ⌘T ↓ Return goes back one, plus Reopen for tabs you closed. ⇧Return opens a page behind the one you are on, ⌥Return opens it in a split, ⌘1–9 takes a row by number, and Escape leaves you exactly where you were, with no stray blank tab. The sidebar's New Tab row and the strip's + open the same card; an extension's new tab page still gets its tab.
- **A Space page for everything about a space.** Click the current space's icon at the foot of the column (another space's icon still switches to it, so a second click opens the page) or the icon in its title row, or use Edit Space… from the space menu or ⌘K: one card with a live preview of the column in light or dark, the name, an icon (none, 26 symbols or any emoji), the look — Colour, Gradient, Picture (with the pictures already used to pick again) or Animated (a scene and its speed) — intensity, grain, a blur for a picture or a scene, and a tone slider from Dark through Normal to Bright that snaps to Normal in the middle; profile and Delete Space are there too. A space toned dark gets light titles and white-translucent rows even in light mode, and one toned bright gets dark ones in dark mode. `./bench spaces page N`, `spaces tap N|header`, `spaces theme N blur|tone|motion|speed …` and `spaces picture N PATH [light|dark]` drive it from the shell.
- **The sidebar looks like Arc's.** Lights, a hide-sidebar door, and back / forward / reload share the top row; the address sits under it (click for ⌘L); the favourites are Arc's wide grid; the space's icon and name head the list; rows are taller with larger titles; New Tab and today's tabs follow the kept rows in one scroll instead of being pinned to the bottom; the foot shows every space's icon (the current one in colour) between the library door and a plus. Arc imports bring each space's emoji and theme, pick the right spaces container, and no longer let the archive sweep close Arc's open tabs on first launch.

- **Spaces wear themes: a colour, a gradient, a picture, and grain.** Edit Space › Theme picks up to three colours (a gradient from the first two or three), a picture laid under the colour, how strongly the column wears it and a film grain — every change live on the column behind the popover. Everything the column draws on top is a translucent white or black, so rows and the live pill read the same over a flat colour, a gradient or a photograph, light or dark. Arc's themes come over with `arc-import` and Flow (colours, intensity, grain), the named colours are retuned so green and teal read as sage and sea glass rather than neon, and a theme written without its intensity or grain still loads. `./bench spaces theme N colors|intensity|grain|image|clear …` sets one from the shell, and `./bench spaces picture N PATH` draws the editor to a PNG.
- **You can always see who is driving, and what they are doing.** The pill, the ring around the page, the on-page trail and the timeline that used to belong to Jev runs alone now cover every hand that is not yours: an agent on the loopback server calling `browser_*` tools one at a time (phi, Claude Code, the `copper` CLI — named by what it said at `initialize`), a bot through an agent link (`@dev-s · agents`), and the agent in Copper's own pane. The pill says *phi is driving* (the dot solid during a call, breathing while it thinks); ⌥⌘J's pane — now the **Driver Timeline** — shows one row per call in plain words (*Clicking Search button · 600 ms · CLICK → page changed*, a failed call in red with its error) under the latest thing the driver said about what it is doing; clicks, typing, hovers, drags and scrolls draw the same trail on the page Jev's did. Every `browser_*` tool takes an optional `reason` (one sentence, shown, never acted on) and the server's instructions ask agents to pass it along with `element`. **Stop** takes the browser back from an agent too: its next calls are refused for 30 s with words it can act on, the refused attempts show in the timeline, and *Let it back in* ends that early. An agent's run stays live 30 s past its last call and picks up again if the same driver is back within three minutes. `./bench drive …` and `./bench render drive PATH` for scripts; `docs/agents.md` › *Who is driving*.
- **Bitwarden sign-in takes email two-step codes and new-device codes.** `bw login` runs with its prompts on — stdin/stdout/stderr piped, stderr watched for *Two-step login code:*, *Two-step login method:* and *New device verification required…*, the code written to stdin when you have it — instead of `BW_NOINTERACTION`, which could only fail with "Code is required." once Bitwarden had emailed the code. Settings › Passwords › Bitwarden asks for the code as a second step (*Enter the code Bitwarden emailed* with Send again, *Enter your authenticator app code*, *Touch your YubiKey*, *New device — enter the emailed code*), lists the methods when the account has several, re-arms after a refused code, and opens on the code step when a sign-in started from `copper bitwarden login` is waiting. `copper bitwarden login -` answers `needs: "code"` / `needs: "method"` and finishes on a second call with `otp`; `copper bitwarden cancel` lets a waiting sign-in go. Verified against Vaultwarden with email-only, email + authenticator, wrong-code and cancel paths; `./bench bw login … [--method N]`, `bw code OTP`, `bw cancel`, `./bench render bitwarden PATH`.

- **More than one window.** ⌘N (File › New Window) opens another browser window into the same Spaces and tab rows. Each window keeps its own current space and active tab; selecting a tab visible in another window hands its single web view over and leaves the other window on a neighbouring tab. Closing a window forgets only its view state, while quitting restores every window. The menus, keyboard and agents over MCP act in the window in front. `./bench windows [new|open N URL|key N|space N INDEX|select N TAB|closetab N TAB|close N|saved|quit]`, `./bench mouse … --window N` and `./bench window PATH N` drive and picture them in a test world.
- **Updates are downloaded and verified before you are asked.** A newer release on the feed is fetched in the background, checked against the manifest's SHA-256, unpacked, and checked for bundle id, version and a verifying code signature; only then does Settings › Updates (and ⌘K) offer Update, which backs up the tab session, swaps the verified bundle in where Copper runs and relaunches. Homebrew is no longer in the update path (the cask now declares `auto_updates`; `brew upgrade --cask copper` by name still works). Every failure is a sentence where it happened — under the release with Retry, or as *The last update didn't finish* with Open log — and a refused swap puts the old bundle back. Fixes the update that reported "Updated to 1.0.20260929.32" while leaving .31 in place, and the one that failed silently once Homebrew had lost track of the install ("already an App at /Applications/Copper.app"). `./bench updates stage` and a `dry-run` mode drive it in a test world.
- **Arc's sidebar comes over as Arc had it.** Folders keep Arc's exact order — a folder's tabs either side of the folders inside it, under one header — come in open or shut as Arc's window left them, and empty folders come too, standing where they stood; Today keeps Arc's order rather than regrouping by folder. A split view comes back as a kept split: picking either half opens the pair again, picking another tab leaves it, and closing the split ends it; kept splits ride in the session. Both `arc-import` and Flow's Arc move do this, Flow no longer renames a second space's `Misc` to `Misc (Arc)` (which cut its subfolders loose), New Folder Inside and Rename no longer trip over another space's folder of the same name, and `./bench groups plan [today]` prints a block as the column draws it.

- **Control-Tab can be most recent.** Settings › Tabs chooses between the next tab in the row and the tabs used most recently; hold Control for the quiet switcher strip, or tap for a quick back-and-forth.
- **Let ⌘K remember the whole browser.** Arc/Chrome history imports are uncapped (with a one-time Settings/command nudge), kept tabs from every space are scored with favourites/Saved badges, and address completion matches host segments as well as titles. Repeated imports merge without double-counting visits.
- **You can always see which tab you are on.** The live row in the sidebar is paper on a slightly deeper column — at least 1.25:1 against the ground in every space colour, light and dark — with a soft shadow, a one-point ring, a short bar of the space's colour beside it and a semibold title; the live favourite gets the same ring and shadow. Picking a tab by keyboard, a link or a space switch scrolls the sidebar to bring its row into view (without the glide under Reduce Motion). In the tab strip the live tab lifts off on the same shadow and its title is semibold.
- **Downloads have a quiet door.** A progress ring, speed and ETA, cancel/retry, Finder actions, an unseen badge, a full ⌘⇧J panel, an Open Downloads Folder command, and a probe fixture replace the old start-and-silence flow.
- **Sign the Mac's Copper into Bitwarden from agents, and watch Jev drive it.** `copper bitwarden status|login -|lock|logout|sync|policy` (loopback `copper/bitwarden`, never reachable through the agent link) signs a headless Copper in: an API-key login (`bw login --apikey` with `BW_CLIENTID`/`BW_CLIENTSECRET` in the child's environment only) or email + master password with an authenticator/email/YubiKey code, then unlock, then the agent-access policy (the `Agents` folder or everything) and stay-unlocked. Secrets come on stdin as one JSON object, never argv. Every answer is a status report (`cli`, `cliVersion`, `state`, `email`, `server`, `lastSync`, `agentAccess`, `stayUnlocked`, `counts`) that holds no secret. `bw` is also found at `SEARCH_BW_PATH` and the installed CLI. Over the agent link, `jev_run`/`jev_step` now stream live `progress` frames (the JevProgress trace: cycles, phases, outcome, page; throttled to 400 ms, 16 KB max, `final: true` before the reply), and a `cancel` frame stops the run as `stopped`. Tool results carry `_meta.summary` (`done · 7 actions · 12.3 s · example.com`) for the app's audit.
- **Jev no longer hangs after a click that navigates.** The post-action settle wait is capped at 1 s: a form submit could leave WebKit's callback unanswered and the run stuck in "Watching the page settle".

- **Copper branding.** About and Welcome now use the copper-plate app icon, show the actual version and build, and keep the Search lineage attribution; extension prompts, update messages, defaults, and the installer say Copper.
- **The keychain asks once, for the account you picked.** Drawing the list of saved accounts under a sign-in box used to read every saved password; each item kept by an earlier build made the keychain put up its dialog, one after another, on every click into the field — Google sign-in was unusable. Lists are now names only; the secret is read when you pick an account, copy it, or show it.
- **Bitwarden sits beside the keychain in the browser.** Connect an existing vault in Settings › Passwords › Bitwarden (bitwarden.com, EU, self-hosted, or Vaultwarden), and Copper merges its saved logins into the under-field picker, TOTP included; choose Bitwarden as the destination for new save offers without changing where keychain fills come from. `./bench bw status|server|login|unlock|lock|sync|candidates|share` exercises the isolated backend for probe worlds; install the CLI with `brew install bitwarden-cli`.
- **Autofill everything from Bitwarden.** Identities fill shipping and address forms, cards fill checkout fields, custom fields match by label, and most-used usernames appear when a site has no saved account. The new Settings › Passwords “Fill addresses and cards” switch controls the picker, agent access covers cards and identities, and `./bench bw identities|cards|fields|usernames|counts|autofill` probes the unlocked cache without returning secrets.
- **Agents can sign in for you without receiving the secret.** `browser_sign_in` fills (and submits by default) a shared account in-process; `copper signin [--account USER] [--otp] [--no-submit] [--json]` is the terminal form, and Jev's `SIGN_IN` control uses the same password fill when a password field and permitted candidate are present. Settings › Passwords › Agent access owns the share-everything switch and per-account toggles; a Bitwarden `Agents` folder allows an item, while `copper-agent: deny` always denies it. The sign-in result, CLI output, and Jev SIGN_IN traces contain status, host, source, and usernames only — never the password, TOTP code, or session key.
- **Agents: link this browser to more than one agents app.** Product-neutral naming everywhere; Settings › Agents shows one card per app with Add/Remove; `copper link [--app SELECTOR] add|remove|…`; announcements read `@bot · app · tool`; existing single-app configurations keep working unchanged.
- **Copper passkeys.** Unentitled builds now provide a WebAuthn platform authenticator in the page: P-256 keys live under `Copper Passkeys` in the login keychain, Touch ID proves create and sign-in, Settings lists credentials, and `./bench passkeys` exercises isolated test worlds. Existing iCloud Keychain passkeys and cross-device hand-off remain unavailable.
- **Flow — move in from Chrome or Arc.** A one-button sheet imports tabs, spaces, pins, groups, bookmarks, history, passwords, signed-in cookies, Google Password Manager passkeys and extensions, with sleeping tabs and one macOS key prompt. `./bench flow` exercises sources, scans and test-world moves.
- **Safe CLI and session recovery.** `copper` no longer launches Copper during a probe unless `--launch` (or `COPPER_LAUNCH=1`) is explicit; `copper session list` and `session restore` expose the retained backup, while ⌘K can restore `session.previous.json`. Session writes refuse launch-time empty overwrites, rotate one previous copy before a large drop, and stay atomic.
- **Copper feed updates.** Settings › Updates, ⌘K, and `./bench updates` check the internal feed and can back up the session, upgrade through Homebrew (or the feed installer), and relaunch without losing tabs.
- **Agents drive the window you have open.** Settings › Agents turns on an MCP server on 127.0.0.1 (bearer token, Origin-checked) with Playwright MCP's tool names — `browser_snapshot`, `browser_click`, `browser_type`, `browser_navigate`, `browser_take_screenshot`, `browser_tabs` and the rest — so a skill written for Playwright works on your real tabs and sign-ins. Clicks and keys arrive as real events; refs come from an accessibility snapshot. Copy-config buttons for Claude Code / phi (HTTP) and Claude Desktop (`--mcp-stdio` pipe, launches Copper if needed). `./bench agent`.
- **Jev mode — ultrafast.** Settings › Agents › *Let the agent hand Copper a goal* adds `jev_run`, `jev_step` and `jev_observe` to the MCP: browser-use's [jev-ultrafast](https://github.com/browser-use/jev-ultrafast) loop ported to run natively in the tab you have open. One TypeSafe request per cycle picks the operation (CLICK, TYPE_TEXT, SELECT, SCROLL, WAIT, DONE, BLOCKED) and an indexed element at once; the router writes any text; freshness guards and occlusion checks run before every real click or keystroke. An agent hands over one plain-English goal and gets the trace back in seconds ("open the Wikipedia article on Gödel's incompleteness theorems": 2 actions, 5.2 s). `jev_extract` reads values off the page as one JSON object (optionally to a schema). A **Text model** field picks the small model that types and extracts, separate from the grouping router. Two **Copy prompt** pills — one for the Playwright-shaped tools, one for Jev mode — give the agent a paragraph on where Copper listens, the token, and what to call. `./bench agent jev on|off`.
- **The agent in the window (⌘E).** Copper as an MCP *client*: a chat pane beside the page whose model has Copper's own tools bound locally — `browser_*`, and the Jev tools when Jev mode is on — plus whatever MCP servers `mcp.json` names (the shape Claude Code and phi read; Streamable HTTP and stdio, `${VAR}` from the environment), shown as `server__tool`. ⌘⇧E is *Ask About This Page*. Tool calls are chips you can read; screenshots go back to the model as pictures. Settings › Agents › *The agent in the window*: model, page context, mcp.json, connected servers. `./bench agent ask|chat|servers`.
- **Jev-first terminal setup.** The bundled `copper` CLI now installs with `copper setup phi|claude|cli|status`; phi and Claude Code get eager Copper tools plus a `/jev` command whose first action is `mcp_copper_jev_run`, with endpoint and bearer-token merges kept at mode 0600. The generated prompts put frontmatter first and retain the setup marker for status checks.
- **Tab groups**, with a colour and a header in the sidebar; fold, rename, recolour, ungroup, close all. Drag a tab into a run to join it. ⌃G, the tab's context menu › Group, and a Groups menu.
- **Smart grouping.** A second after a page lands, Copper weighs it against your groups: your rules first (`github.com → Code`), then Jev (TypeSafe System One — one typed choice, ~200 ms, with a confidence), then the router (LiteLLM, Sonnet by default) when Jev is unsure or a new group needs a name, then a plain same-site match with no keys at all. Ask mode puts a one-line chip under the tab; Automatic just does it. Only the tab's address and title and your group names leave the Mac.
- **Sign in with your Claude account, pick Haiku, Sonnet or Opus.** Settings › Intelligence › Model access chooses between an API key for a gateway and a Claude account signed in like Claude Code (OAuth in a tab, tokens in `claude.json`, refreshed silently); the model is one choice — Haiku, Sonnet or Opus, Sonnet by default — in the agent pane's header and in Settings; `copper claude status|signin|paste|signout`, `copper intelligence set --lane --model`.
- **Settings › Intelligence**: paste a Jev key and a router key (eye/paste buttons, 0600 file beside the session), pick the router model, set Jev's confidence bar, add rules, and test both lanes with one click. `./bench ai`, `./bench groups`.

- **Spaces you can tell apart, and manage.** The column now has a **space header** under the traffic lights — the space's icon and its full name; hover for the tab count, click for the space menu. The foot draws every space as a **22pt icon chip** (emoji, SF symbol, or first letter, in its colour; the current one on the column's paper-white pill) instead of 8pt dots, names a chip the moment you hover it, scrolls sideways under a soft edge when there are too many, and never cuts the current name to a letter again. Drag a chip to reorder, or use Move Left / Move Right. **Edit Space…** (from the header, a chip's right-click, or ⌘K) is one popover for name, icon (15 symbols or any emoji), colour and profile, re-tinting the column live. **Delete Space…** asks first and offers *Move Tabs to <neighbour> & Delete* beside *Close Tabs & Delete*. Colours have **names** — Graphite, Copper, Orange, Yellow, Green, Teal, Blue, Indigo, Pink, Red — everywhere they used to be degrees, and a new space takes the first colour no other space is wearing (the `+` opens its editor at once). Spaces from older sessions keep their hue; grey ones stay grey. `./bench spaces icon|colour|reorder|edit|delete|answer`, `remove N --keep`, `./bench ui width N`; [docs/spaces.md](docs/spaces.md).

### Fixed (Copper)

- **Animated space backdrops keep moving through a space switch or a swipe.** The column now keeps one scene for its whole life: a switch between animated spaces fades the colours (and the clock) to the new space in the shader in about 0.3 s instead of snapping, a still space in between hides and pauses the scene rather than destroying it (before, coming back started a fresh WebContent process and the scene from t = 0), and a swipe no longer starts a second web view for the curtain — the live scene stays under the moving rows, mixing towards the arriving space as your fingers go. The scene's clock is the wall's from a launch-fixed epoch, so a space's scene is always where it would have been had it kept drawing, and changing its speed bends the motion instead of jumping it. After a swipe commits, the arriving space's picture fades into the live column over the settle rather than popping. `./bench backdrop` shows the scene's process, clock and frames.
- **Stop no longer breaks the agent's next question.** Stopping the agent while a model request or a tool call was in flight could leave a tool call in the history with no answer after it, and every later question failed with `router 400: … tool_use ids were found without tool_result blocks immediately after`. The cut-off call is now answered with *Cancelled by the user* before anything is sent, a run that is still unwinding after Stop can no longer write into the next question's history, and a failed request no longer drops the last tool result.
- **⌘K goes to the page first.** A web app with its own ⌘K palette — Tuesday, Linear, Slack, Notion, GitHub — now gets the key, as in Safari: the browser's search opened over it and the app's never did. A page that does not use ⌘K hands it back and the tab search opens as before. `./bench key … --app` reports `pageFirstOffered`/`pageFirstReturned`.
- **⌘← and ⌘→ move the caret when you are typing.** In a page's text box, the omnibox, or the agent's composer they jump to the start and end of the line (⌘⇧ extends the selection), as in Safari; with nothing editable focused they still go back and forward. A key the page hands back with nowhere to go is kept quiet instead of beeping.
- **Middle-click opens a link in a new tab behind the current one**; ⇧+middle-click brings it forward. WebKit numbers mouse buttons differently from AppKit and the check matched the right button instead of the wheel, so the page navigated in place. A ⌘- or middle-clicked `target=_blank` link now stays behind too.
- **Mouse buttons 4 and 5 go back and forward over a page** — in whichever pane of a split the pointer is over. Over the sidebar they switch spaces; middle-click on a sidebar row or favourite closes that tab.
- **The agent and Jev panes are easy to close.** Every header button is a real 26pt door with a hover wash (the split's toolbar too), a second "close all" door appears whenever more than one pane is open, **Close All Panes** (⌘⌥E) and **Jev Timeline** (⌘⌥J) join the menu and ⌘K, and Escape closes the pane nearest the edge when the keyboard is not in a page.
- `./bench key ID TEXT [--app]` presses ⌘/⇧/⌥/←/→/⎋ and can send through the app's key monitor; `./bench ui focus none` hands the keyboard to the window; `./bench mouse back|forward|middle [X Y] [--shift]` clicks the other mouse buttons in-process; `./bench probe` reports `firstResponder` and `lastLinkClick`.

## 1.0 — 23 September 2026

The first version. A browser for the Mac with nothing in the way: tabs in a row or down the side, pinned tabs that keep their place, and one field for addresses and searches. Ads blocked before they load, passwords and passkeys in your keychain, anything on a page hidden for good, reading mode, floating video, Chrome extensions from the Chrome Web Store (macOS 15.4 or later), and tabs that sleep after half an hour. 2.9 MB, on the engine already in macOS.
